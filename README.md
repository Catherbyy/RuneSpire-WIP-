# RuneSpire 🧙‍♂️🃏
A turn-based, RuneScape-themed card battle game inspired by **Slay the Spire** — built in Python.

## 🎮 Features
- Deck-based combat system
- Energy + turn-based battle loop
- RuneScape-style flavor (Wind Strike, Lobster Heal, etc.)
- CLI interface using pure Python
- Modular file structure

## 🛠️ How to Run
1. Clone or download the repo
2. Open terminal in the project folder
3. Run the game:
   ```bash
   python game.py
